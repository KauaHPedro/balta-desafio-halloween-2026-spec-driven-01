## 🎃 Halloween - Desafio 1

Oi, eu sou o Kauã e este é o espaço onde compartilho minha jornada de aprendizado durante o desafio **Halloween 2026**, realizado pelo [balta.io](https://balta.io). 👻

Aqui você vai encontrar projetos, exercícios e códigos que estou desenvolvendo durante o desafio.

### Sobre este desafio
Neste desafio o objetivo é consolidar os fundamentos do Spec Driven Development, criando uma constituição, especificação, planejamento e tarefas manualmente para serem implementadas pela IA posteriormente.

#### O que foi implementado
- API para geração de senhas fortes.

- Persistência das senhas geradas, associadas a um GUID.

- API para recuperação de senhas por GUID.

- Validação de GUIDs e tratamento de identificadores inexistentes.

Neste processo eu aprendi:
✅ Como estruturar os artefatos de um projeto utilizando SDD.

✅ Como definir regras e requisitos antes de iniciar a implementação.

✅ Como decompor a implementação em tarefas menores e rastreáveis.

✅ Como utilizar IA para implementar uma solução a partir das especificações.

✅ Como testar manualmente os endpoints de uma API utilizando o Postman.

Optei por não seguir a sugestão de utilizar o GitHub Copilot na etapa de implementação. Aproveitei o desafio para explorar outras ferramentas e realizar a implementação utilizando o DeepSeek com o OpenCode.
